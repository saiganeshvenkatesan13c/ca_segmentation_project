This project uses time-series calcium imaging data and corresponding segmentation masks, recorded at the Kirkeby Lab.

Data consists of:
- Image stacks (T × Y × X) stored as TIFF files
- Ground-truth segmentation masks stored as label images

Small subsets of the calcium data can be found on the [LUMIN Github page](https://github.com/kirkebylab/LUMIN). //
For more information, refer to the [LUMIN paper](https://www.nature.com/articles/s41598-026-40269-0).
