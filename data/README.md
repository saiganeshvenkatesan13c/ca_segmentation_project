This project uses time-series calcium imaging data recorded at the [Kirkeby Lab](https://renew.ku.dk/research/kirkeby_group/), and corresponding segmentation masks.

Data consists of:
- Image stacks (T × Y × X) stored as TIFF files
- Ground-truth segmentation masks stored as label images

Small subsets of the calcium data can be found on the [LUMIN Github page](https://github.com/kirkebylab/LUMIN).

For more information about the data, refer to the [LUMIN paper](https://www.nature.com/articles/s41598-026-40269-0).
